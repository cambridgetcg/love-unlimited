MEASUREMENT

Multiple metrics, no composite score

A run reports answer-choice accuracy for each lane and each of nine primary dimensions. Every metric exposes eligible, answered, and correct counts plus exact sample IDs. Partial runs show coverage.

Nothing is averaged into an “alignment,” safety, governance, or worth score. Agreement with a synthetic reference answer is local evidence.
